# 页 Page

页面是路由级容器，一个路由一个页面。它给面板提供定位参照系与停靠位，页面自己只决定「东西摆在哪」，不关心摆的是什么。

## 演示

```demo
basic.vue
stacked.vue
```

## API

### Page Props

页面本身没有属性，透传的属性（`class`、`style`、事件）会落到 `.n-page` 上。

### Page Slots

| 名称    | 参数 | 说明     |
| ------- | ---- | -------- |
| default | `()` | 页面内容 |

### 停靠位

`PanelAnchor` 一共七个值：

| 值              | 位置     |
| --------------- | -------- |
| `top-left`      | 左上角   |
| `top-center`    | 上边居中 |
| `top-right`     | 右上角   |
| `center`        | 正中     |
| `bottom-left`   | 左下角   |
| `bottom-center` | 下边居中 |
| `bottom-right`  | 右下角   |

停靠位先于页面内容渲染，所以面板挂载时就能拿到容器，不需要 `nextTick` 或重试。停靠位是覆盖层而不是布局块：它不影响页面排布，也不会挡住底层内容的点击，只有真正挂进去的面板可以交互。同一个停靠位上的多个面板按挂载顺序竖向堆叠，间距 10px。

### 样式契约

| 类名 | 说明 |
| --- | --- |
| `.n-page` | 定位参照系（`position: relative`、`overflow: hidden`） |
| `.n-page-anchors` | 停靠位覆盖层（`z-index: 30`，不接收指针） |
| `.n-page-anchor--<anchor>` | 单个停靠位（`flex column`、`gap: 10px`） |

### 约定

- 页面不感知路由、不读业务数据，面板的位移 / 缩放 / 显隐由页面决定是否持久化；
- 面板与页面之间没有 import 关系，只通过注入的停靠位注册表协作，所以面板可以脱离页面单独使用（找不到停靠位时原地渲染，不报错）。
